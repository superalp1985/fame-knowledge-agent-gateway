# Editions

This directory separates release-facing edition notes from the shared runtime, workbench and gateway code.

## Chinese Edition

`versions/chinese/` documents the current full Chinese edition. The working implementation remains at the repository root:

```text
knowledge/
workbench/
runtime_server/
memory/
asset_store/
```

## English Edition

`versions/english/` is a clean English seed. It starts from a language-centered knowledge structure:

```text
Language Tree Hub
-> Professional Knowledge
   -> Programming
   -> Design
```

The English knowledge base is intentionally skeletal for now. Subject-by-subject expansion should keep the FAME route parameters, project-memory isolation, context-health rules, tool governance and multimodal light-index boundary unchanged.
