# Chinese Edition

The Chinese edition is the current full version of FAME Knowledge Agent Gateway.

It uses the repository root as its active implementation:

```text
knowledge/        # public Chinese knowledge-net base
workbench/        # 3D/2D workbench
runtime_server/   # HTTP and MCP runtime gateway
memory/           # public project-memory overlay seed
asset_store/      # public multimodal light-index seed
```

The private local knowledge source remains outside the public edition:

```text
knowledge_backup/
```

The Chinese edition keeps the current mechanisms:

- route-first reasoning
- Language Tree-centered knowledge organization
- abstraction and association traversal
- FAME edge parameters
- project-memory overlay isolation
- full memory retention
- scoped semantic indexing
- Tool Gateway enforcement
- MCP and HTTP agent access
- multimodal asset database boundary

Use this edition when continuing the existing Chinese knowledge-net work.
