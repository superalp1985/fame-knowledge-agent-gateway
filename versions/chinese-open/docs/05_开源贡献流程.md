# 开源贡献流程

中文开源版的贡献目标是保持知识网可扩展、可验证、可被 Agent 按需调用。

## 贡献前检查

贡献者先确认：

- 新内容属于哪个 subject。
- 新内容处在哪个 abstraction_level。
- 是否有权威来源或自写经验依据。
- 是否需要进入图谱，还是只进入数据库、规则库或索引库。
- 是否会引入许可证、隐私、路径或密钥风险。

## 推荐流程

1. 在 `knowledge/source_registry.json` 登记外部来源。
2. 在对应 subject 的 `taxonomy.json` 增加分类节点。
3. 把详细解释写入 `knowledge/database/content_units.jsonl`。
4. 如果是可执行规则，写入 `knowledge/rules/*.json`。
5. 如果 Agent 需要直接调用，写入 `knowledge/route_index.json`。
6. 如果是失败教训，保留负值 FAME 参数，写成 lesson 或 failure pattern。
7. 运行 `npm run check:chinese-open` 和 `npm run release:check`。

## 图谱录入判断

适合进图谱：

- 学科入口。
- 稳定的二级方向。
- Agent 高频路线。
- 能帮助可视化定位的关键规则。
- 负值 FAME 教训入口。

不适合直接进图谱：

- 长篇教程。
- 大量例题。
- 原始日志。
- 大文件、多模态原始数据。
- 外部项目源码。

## 数据源贡献

成熟数据源先写入 `knowledge/database/data_sources.json`，并在 `docs/06_成熟数据源导入策略.md` 对齐导入策略。

导入前必须补齐：

- 许可证和 NOTICE 需求。
- 快照日期或版本。
- schema 映射。
- 样本规模。
- 去重策略。
- 隐私和敏感字段处理。
- 导入后校验脚本。

未完成以上检查前，不得把原始数据导入核心知识网。ShareAlike、署名、版权复杂或隐私敏感数据必须进入隔离库，只能把自写摘要、来源链接和少量索引引用接入知识网。

## FAME 更新原则

FAME 参数必须有来源：

- 测试通过可提升 `epsilon` 和 `rho`。
- 工具调用稳定可提升 `kappa`。
- 用户反馈贴合可提升 `chi`。
- 失败复发可降低 `mu`，并给 `delta` 负值。
- 许可证、安全、时效风险上升时提高 `risk`。

不要为了让图好看而人工虚高参数。

## 工程记忆晋升

工程 overlay 不能自动写入核心知识网。晋升前需要确认：

- 经验是否脱离具体项目仍然成立。
- 是否有可公开引用的证据。
- 是否不会泄漏私有信息。
- 是否能写成通用 rule、route 或 lesson。
