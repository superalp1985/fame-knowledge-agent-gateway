# 成熟数据源导入策略

本项目可以借鉴成熟数据源，但不能把大规模外部数据直接倒进核心知识网。核心原则是：

- 知识网保持轻量，只保存摘要、路由、来源和索引引用。
- 大规模数据进入外部数据库、对象存储或隔离索引。
- ShareAlike、署名、版权复杂或隐私敏感数据不得混入 Apache-2.0 核心内容。
- 导入前必须记录许可证、版本、快照日期、schema 映射和样本校验结果。

## 优先候选

| 数据源 | 价值 | 初始用途 |
| --- | --- | --- |
| Wikidata | 通用实体、多语言别名、外部 id | 作为实体和别名外部索引，不导入全图 |
| OpenAlex | 学术元数据、概念层级、引用发现 | 辅助寻找权威论文和学科来源 |
| OpenCitations | 开放引用图 | 辅助判断来源关系和研究路线 |
| Open English WordNet | 英语词汇语义 | 候选词义数据库，注意署名 |
| Library of Congress Linked Data | 受控主题词和分类 | 主题词锚点和分类参考 |

## 隔离候选

| 数据源 | 隔离原因 | 可用方式 |
| --- | --- | --- |
| ConceptNet | CC BY-SA，边质量需过滤 | 只作横向联想候选，不写入核心事实 |
| DBpedia | 派生来源和许可证复杂 | 外部 linked data 参考 |
| Stack Exchange Data Dump | CC BY-SA，内容会过时 | 错误模式统计、负值 FAME 候选 |
| Software Heritage | 源码许可证各异 | 只保存 artifact id、摘要和链接 |
| GitHub Archive | 用户行为事件、体量大 | 只做项目活动和案例候选筛选 |
| Libraries.io | 生态数据会过期 | 依赖图和供应链信号隔离索引 |
| arXiv Bulk Data | 论文许可证不统一 | 只导元数据和链接候选 |
| Papers with Code | 链接数据集许可证各异 | AI 任务和 benchmark 候选索引 |

## 导入门禁

每个数据源进入样本导入前，必须补齐：

1. `source_id`
2. 许可证和 NOTICE 需求
3. 快照日期或版本
4. 数据字段 schema
5. 与本项目 subject、route、content unit 的映射关系
6. 样本规模
7. 去重策略
8. 隐私和敏感字段处理
9. 导入后校验脚本

## 推荐第一批样本

1. Wikidata：只抽语言、逻辑、数学、计算机科学相关实体的 id、label、alias、external id。
2. OpenAlex：只抽核心来源、概念层级、论文元数据和引用关系，不导论文正文。
3. Open English WordNet：抽少量词义关系做语言树语义层验证。
4. Stack Exchange：抽 PowerShell/Git/Python 高频错误标题和链接，隔离为负值 FAME 候选，不导正文。
5. Software Heritage/GitHub Archive：只用于筛选公开工程记忆案例候选。
