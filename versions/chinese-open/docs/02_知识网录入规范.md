# 知识网录入规范

## 节点类型

| 类型 | 用途 |
| --- | --- |
| `hub` | 语言树中枢或学科入口 |
| `discipline` | 一级学科或稳定大分支 |
| `field` | 二级方向 |
| `topic_cluster` | 主题簇 |
| `knowledge_point` | 具体知识点 |
| `route` | 可被 Agent 调用的知识路线 |
| `rule` | 工具、语法、验证或安全规则 |
| `lesson` | 失败教训或负值 FAME 路线 |
| `index_ref` | 数据库、规则库、索引库引用 |

## 抽象层级

| 层级 | 含义 | 示例 |
| --- | --- | --- |
| `L0_meta` | 元概念和组织原则 | “语言树中枢负责路由所有知识” |
| `L1_discipline` | 学科或大分支 | 数学、计算机科学 |
| `L2_field` | 二级方向 | 代数、人工智能 |
| `L3_topic` | 主题簇 | 群论、搜索算法 |
| `L4_method` | 方法和规则 | 归纳证明、schema 校验 |
| `L5_operation` | 可执行操作 | 调用工具前读取工具说明 |
| `L6_case` | 案例、经验和教训 | PowerShell 引号错误复盘 |

## 边类型

| 类型 | 含义 |
| --- | --- |
| `contains` | 层级包含 |
| `abstracts_to` | 向上抽象 |
| `specializes_to` | 向下具体化 |
| `routes_to` | 任务路由 |
| `associates_with` | 联想迁移 |
| `validates_with` | 证据或测试验证 |
| `warns_against` | 失败教训或负向约束 |
| `indexes` | 图节点引用外部内容单元 |

## 录入流程

1. 确定节点属于哪个学科分支。
2. 确定节点的抽象层级。
3. 先回到语言树中枢做术语归一，把语义树位置固定到 canonical term。
4. 写一句不超过 120 字的 `summary`。
5. 如果需要详细说明，新增 `content_unit`，节点只保存引用。
6. 添加来源引用，许可证不明的资料只登记来源，不导正文。
7. 添加 FAME 默认参数。
8. 为 Agent 调用补充 route 或 rule。
9. 运行 schema 校验和 release check。

## 禁止事项

- 不把长篇资料塞进图节点。
- 不把私人工程记忆写回核心知识网。
- 不复制许可证未确认的词典、教材、网页全文。
- 不用模糊分类替代学科层级。
- 不删除失败路线；失败路线应转成 `lesson` 或负值 FAME 边。
