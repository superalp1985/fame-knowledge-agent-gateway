# 定位与建设规则

## 项目定位

中文开源知识网是 Agent 的外部知识组织插件基底。它的目标不是把材料堆成检索库，而是让 Agent 在真实工程中按“语言理解 -> 学科抽象 -> 联想迁移 -> 具体执行 -> 验证回写”的路线工作。开源公开范围只正式覆盖编程与工具调用；语言树中枢就是语义树挂点，负责术语归一和抽象路由。逻辑与数学只保留支撑骨架，不做首发全量扩展。

这一版先聚焦确定性强、公开资料足、适合开源协作的科目：

- 语言树中枢（语义树挂点）
- 计算机科学（编程、工程、测试）
- Agent 工具调取
- PowerShell 安全语法
- 逻辑、数学仅保留方法支撑骨架

## 知识网规则

每条知识路线必须同时满足四个层次：

1. 学科层级：从一级学科、二级方向、主题簇到知识点。
2. 抽象层级：从元概念、原则、结构、方法、操作到经验教训。
3. 路由层级：从任务意图、适用条件、上下游依赖到验证方式。
4. 存储层级：图谱存摘要和引用，详细内容进入数据库、规则库和索引库。

## 图谱轻量边界

图谱节点允许保存：

- `id`
- `label`
- `subject`
- `node_type`
- `abstraction_level`
- `summary`
- `source_refs`
- `content_refs`
- `fame`

图谱节点不保存长篇教程、论文全文、原始日志、大型多模态数据。那些内容应进入：

- `knowledge/database/content_units.jsonl`
- `knowledge/rules/*.json`
- `knowledge/indexes/*.json`
- 外部数据库或对象存储

## 语言树中枢

语言树是知识网的中心入口。它负责把自然语言目标转成可执行的知识路线；在本版里它同时就是语义树位置，所有术语先归一到 canonical term，再进入路由：

```text
用户目标
-> 意图识别
-> 术语和别名归一
-> 语法/操作结构识别
-> 语义抽象
-> 学科路由
-> 联想迁移
-> 上下文包
-> 执行和验证
```

旧知识网里的语言树文件暂不直接复制。本版保留机制，重新建立干净、可开源、可审核的中文语言树中枢。

## FAME 路由参数

每条路由和关键边都保留 FAME 参数。第一版使用默认值，后续由测试、工具结果、人工反馈和工程记忆更新。

```text
route_score =
  0.22 * mu
+ 0.18 * chi
+ 0.20 * epsilon
+ 0.12 * kappa
+ 0.10 * nu
+ 0.08 * rho
- 0.06 * abs(delta)
- 0.04 * risk
```

参数含义：

- `mu`：知识路线的有效性。
- `chi`：与当前目标的语义贴合度。
- `epsilon`：证据强度和可验证性。
- `kappa`：可操作性。
- `nu`：新颖或联想迁移价值。
- `delta`：情绪/结果偏差，负值代表失败、风险或教训。
- `rho`：复用稳定性。
- `risk`：安全、许可证、时效或工程风险。

负值路线不删除。它们作为失败教训保留，并在 3D/2D 图里以明显样式显示。

## Agent 强制机制

Agent 接入时必须遵守：

1. 开始任务前读取当前项目规则、路由索引和工具说明摘要。
2. 工具调用前先构造 `ProposedAction`。
3. 涉及写入、删除、网络下载、执行脚本等变更行为时必须经过 `ApprovedAction`。
4. 执行后写入结果摘要、证据、失败模式和 FAME 更新候选。
5. 长任务必须设置自提醒或恢复点，避免中断后丢失工作状态。
6. 解决问题后只把摘要、索引和必要证据留在上下文，完整轨迹放入外部记忆。

## 开源协作边界

允许开源录入：

- 权威分类目录的摘要和链接。
- 自写的知识点摘要、路由规则、案例摘要。
- 许可证允许的词表或工具资源引用。

不应直接提交：

- 未核准许可证的全文资源。
- 私人工程日志。
- 私有 API key、路径、数据库。
- 大型原始多模态数据。
