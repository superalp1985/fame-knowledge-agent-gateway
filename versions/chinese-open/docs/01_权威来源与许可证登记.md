## 登记字段

外部来源必须写入 `knowledge/source_registry.json`：

```json
{
  "id": "source-id",
  "title": "来源标题",
  "publisher": "发布者",
  "url": "https://example.org",
  "subject_refs": ["mathematics"],
  "usage": "taxonomy_anchor",
  "license_review_status": "pending",
  "notes": "只记录摘要和分类锚点，不复制全文"
}
```

## 使用原则

- 确定性知识优先用权威来源对齐。
- 开源仓库里只放自写摘要、结构化索引和来源链接。
- 对许可证不明确的资料，状态保持 `pending`，不得导入正文。
- 后续若引入词典、语料、教材内容，必须先补许可证说明和 NOTICE。
