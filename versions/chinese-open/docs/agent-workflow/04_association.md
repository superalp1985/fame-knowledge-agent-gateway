# 04 多路径联想

开放任务先读取：

1. `language-tree-hub/association_playbooks.json`
2. `language-tree-hub/abstraction_playbooks.json`
3. `language-tree-hub/thought_modes.json`
4. `mathematics/modeling_patterns.json` 或 `mathematics/methods.json`

候选路线最多 5 条，活动路线最多 3 条。

每条路线写明：

- 主学科和相邻学科
- 抽象层级
- 预估收益
- 风险和上下文成本
- 验证钩子
