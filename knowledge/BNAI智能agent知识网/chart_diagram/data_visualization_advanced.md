# 数据可视化进阶规则

数据可视化的目标不是“把数据画出来”，而是让受众看见趋势、差异、异常、结构和判断依据。

## 1. 先问关系，再选图表

- 比大小：柱状图、条形图。
- 看趋势：折线图。
- 看占比：堆叠条、百分比条；谨慎使用饼图。
- 看分布：直方图、箱线图。
- 看相关：散点图。
- 看流向：桑基图、漏斗图。
- 看层级：树图、旭日图、金字塔。
- 看地理：地图，但不要为了炫技用地图。
- 看流程：流程图、泳道图。

## 2. 图表标题写洞察

错误标题：

- “2023 年收入情况”

正确标题：

- “2023 年培训收入增长主要来自高端班扩张”

标题应该告诉观众怎么看，而不是重复坐标轴。

## 3. 去噪 declutter

优先删除：

- 无意义网格线
- 重复图例
- 多余边框
- 3D 效果
- 过多颜色
- 不必要小数位
- 无解释的标签

## 4. 强调 highlight

只突出最重要的数据点：

- 关键年份
- 最大/最小值
- 异常点
- 决策阈值
- 政策变化点

## 5. 反误导规则

- 柱状图 y 轴原则上从 0 开始。
- 不用面积误导数量。
- 双轴图必须谨慎，默认避免。
- 相关不等于因果。
- 样本量不足必须提示。

## 6. 建木图表质量检查

- 图表是否回答了一个明确问题？
- 图表类型是否匹配数据关系？
- 是否有洞察标题？
- 是否有来源？
- 是否有单位？
- 是否突出重点？
- 是否去掉了噪声？
- 是否存在误导？
