# 动画与动效进阶规则

动画的任务是解释变化，不是制造热闹。

## 1. 动效语义

每个动效必须属于以下语义之一：

- 出现：引入新信息。
- 消失：移除旧信息。
- 位移：表达位置/状态变化。
- 缩放：表达重要性变化。
- 变色：表达状态变化。
- 连线：表达关系建立。
- 高亮：表达注意力聚焦。
- 逐步构建：表达复杂结构。

没有语义的动效一律删除。

## 2. 教学动画节奏

- 一个动作只解释一个变化。
- 复杂过程拆成多个小动作。
- 关键变化后保留停顿。
- 旁白、字幕、动画必须同步。

## 3. 常见坏动效

- 所有元素一起飞入。
- 每页都用不同转场。
- 动得太快，观众看不清。
- 装饰动画抢过内容。
- 动画与旁白解释不一致。

## 4. 自动修正

- 动画过多：保留语义动作，删除装饰动作。
- 动画过快：延长 duration，增加 hold。
- 同步失败：以旁白句子重新绑定 cue。
- 信息过密：分步 reveal。
