# Jianmu 交付物分类与定义

## 为什么需要分类

用户常说“做一下”“整理成材料”“弄个课件”。这些表达必须先抽象成明确交付物，否则 full path 会在页数、结构、质量门和导出格式上跑偏。

## 标准交付物

### document

包括：课程大纲、讲稿、报告、研究简报、方案、文稿、摘要、来源清单。

默认质量门：
- 目标和受众明确。
- 结构先于正文。
- 结论、证据、行动建议分层。
- 术语一致。
- 有来源要求时必须保留来源。

### ppt

包括：PPT 草稿、课件、幻灯片、汇报 deck、Marp 草稿。

默认质量门：
- 每页只有一个核心任务。
- 标题尽量是结论句。
- 页面功能类型明确。
- 视觉层级清晰。
- 不把文档直接分页贴进幻灯片。

### video

包括：视频脚本、分镜、旁白、字幕、镜头表、视频项目计划。

默认质量门：
- 时长预算明确。
- 场景/镜头/旁白/字幕分离。
- 每段视频有明确传播目的。
- 音画同步与字幕可读性作为硬门槛。

### image

包括：封面图、视觉参考图、海报、PPT 视觉占位、视频封面。

默认质量门：
- 用途明确。
- 不含难读小字。
- 构图服务主题。
- 风格与主交付物一致。

### audio

包括：旁白、配乐、歌曲、音效设计、朗读音频。

默认质量门：
- 情绪和用途明确。
- 人声可懂。
- 配乐不压主体。
- 导出格式和时长明确。

### pdf

PDF 通常是导出格式，不是独立内容类型。除非用户明确要求“只生成 PDF 表单/文档”，否则 PDF 应附着在 document 或 ppt 后。

## 混合成果包

当用户说“全套”“课程包”“成果包”“PPT 和视频”“课件加讲稿”时，按 mixed_artifact_package 处理。

默认包含：
- document：任务书、课程大纲、讲稿或研究简报。
- ppt：课件或 deck。
- source_list：来源与素材清单。
- 可选 video/image/audio：按用户表达和任务需要加入。

## 抽象规则

- “课程大纲”归入 document。
- “PPT 草稿/课件/幻灯片”归入 ppt。
- “讲稿/文稿/报告/方案/简报”归入 document。
- “视频脚本/分镜/旁白/字幕”归入 video。
- “封面/海报/视觉参考”归入 image。
- “全套/课程包/成果包”触发 mixed_artifact_package。
