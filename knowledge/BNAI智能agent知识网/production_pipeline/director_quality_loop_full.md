# 多模态总导演与质量闭环

## 1. 总导演层的职责

总导演层不直接生成素材，而是决定每个任务应该调用哪些专业知识、用什么表达结构、经过哪些审查、如何自动修正。

职责：

1. 识别主题类型。
2. 选择叙事结构。
3. 选择 PPT 页面系统。
4. 选择视频时间轴。
5. 选择视觉风格。
6. 选择音乐/声音策略。
7. 分配质量门槛。
8. 汇总审查结果并触发修正。

## 2. 标准生产链路

```text
语言树概念
  -> 抽象规律识别
  -> 专业知识检索
  -> 叙事主线
  -> PPT/视频/音乐/图表表达计划
  -> 初稿生成
  -> 截图/音频/关键帧审查
  -> 自动修正
  -> 再审查
  -> final / preview / fail
```

## 3. 质量门槛

### 内容门槛

- 概念准确
- 没有事实冲突
- 结构符合主题
- 有例子或证据

### PPT 门槛

- 无乱码
- 无遮挡
- 无溢出
- 字号达标
- 页面功能明确
- 图表匹配关系

### 视频门槛

- 音画同步
- 字幕安全
- 关键帧可读
- 时间轴完整
- 节奏不拖不乱

### 音乐门槛

- 不压旁白
- 情绪匹配
- 段落完整
- 循环自然
- 结尾不突兀

## 4. 自动修正闭环

每次审查输出必须包含：

- issue_type
- severity
- evidence
- target_file
- suggested_fix
- auto_fixable
- retry_limit

严重等级：

- P0：乱码、文件缺失、不可打开、严重遮挡、音画完全不同步。
- P1：内容错、主线断、关键页不可读、BGM 压旁白。
- P2：美观不足、节奏偏平、层级偏弱。
- P3：风格优化建议。

P0/P1 不得 final。
