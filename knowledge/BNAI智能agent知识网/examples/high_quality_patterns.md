# 高质量样例模式库

## 1. 高质量 PPT 页模式

### 1.1 结论 + 三证据

适用：汇报、研究简报、领导决策。

结构：

- 顶部：一句话结论。
- 中部：三个证据卡片。
- 底部：来源或行动建议。

优点：结论先行，受众不迷路。

### 1.2 左图右文

适用：案例解释、机制说明。

结构：

- 左侧：图、流程、场景。
- 右侧：解释、要点、结论。

注意：图必须承担信息，不做装饰。

### 1.3 流程闭环页

适用：预算绩效、管理闭环、反馈机制。

结构：

- 环形或横向流程。
- 每一步一个短标签。
- 中心写核心目标。

### 1.4 对比决策页

适用：方案 A/B、改革前后、政策选择。

结构：

- 横向双栏。
- 同维度比较。
- 最右侧给判断。

### 1.5 数据洞察页

适用：趋势、结构、异常、对比。

结构：

- 标题写洞察。
- 图表只保留必要元素。
- 高亮关键点。
- 角落标来源和口径。

## 2. 高质量视频 scene 模式

### 2.1 问题引入 scene

- 旁白：提出痛点。
- 画面：真实场景或抽象问题图。
- 音乐：轻微张力。
- 结尾：引出机制。

### 2.2 机制解释 scene

- 旁白：一步一步解释。
- 画面：流程/结构逐步 reveal。
- 动效：只对应概念变化。
- 音乐：低存在感。

### 2.3 案例验证 scene

- 旁白：讲一个具体例子。
- 画面：案例卡片 + 关键变化。
- 字幕：关键词，不逐字堆满。

### 2.4 总结收束 scene

- 旁白：回到主线。
- 画面：三点总结。
- 音乐：稳定收束。
- 结尾：自然 fade out。

## 3. 高质量音乐模式

### 3.1 稳重教学底乐

- 低密度。
- 弱旋律。
- 简单和声。
- 不压旁白。

### 3.2 风险提示底乐

- 低频轻微张力。
- 留白。
- 不做恐怖片效果。

### 3.3 总结上扬底乐

- 稳定节奏。
- 轻微明亮和声。
- 不煽情。
