# 建木 Agent Studio

这是建木知识网的连续项目：把知识网作为第一知识源，整合成熟开源项目，做一个可备课、可研究、可制作课件和视频的 Agent 工作台。

## 目标
- 优先调取建木知识网
- 支持联网搜索作为补充证据
- 统一在一个 Agent 窗口里完成：研究、备课、PPT、讲稿、视频脚本、成片
- 采用成熟开源项目拼装，不自研重轮子
- 由 Claw Code 作为中控编排

## 第一版边界
- 先做课程/研究/课件生产，不追求复杂多智能体框架
- 先跑通文档化流水线，再逐步接 PPT、TTS、视频合成
- Web 搜索默认只做补充，不直接污染知识网

## 目录约定
- `docs/`：工程文档与方案
- `src/`：编排代码
- `tools/`：接入的开源项目封装
- `prompts/`：系统提示词与角色提示
- `templates/`：PPT/讲稿/视频模板
- `outputs/`：生成结果
- `cache/`：临时缓存

## 当前状态
- 2026-05-21：立项，准备调研成熟开源项目并确定接入方案

## UI 外壳策略
- 最终窗口首选 **Tauri**：Rust 底层 + WebView2 前端。
- 选择原因：体积小、内存占用低、安全性高，适合本地知识资产与工具沙盒。
- v0.1 先跑通文件型流水线，v0.2 再接 Tauri UI。

## 部署理念
- 不只封 UI，也封运行环境。
- 目标是把 Agent 做成可移植的本地工作台：装到哪台电脑都能直接跑。
- Claw Code 负责中控，后台调度成熟开源工具，统一输出成果。

## API 网关策略
- 在 Claw Code 中控前置 API Gateway。
- 用户/前端只调用网关，网关统一封装内部工具、AI 模型和建木知识网。
- 目标：一个入口，集中治理，统一权限、日志、任务、错误和结果。

## 模块接入口径
- DocAgent：长文档理解与审查。
- DeepPresenter / PPTAgent：幻灯片生成。
- PresentAgent-2：视频主链路。
- Code2Video：动画增强。
- 这些模块都挂在 Claw Code 中控之下，通过 API Gateway 统一调度。
