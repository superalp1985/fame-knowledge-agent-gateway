# 案例与反例库

## 1. PPT 反例

### 反例：一页塞满文字

问题：受众读屏，不听讲；字号变小；主线消失。

修正：拆成“结论页 + 证据页 + 讲稿备注”。

### 反例：图表没有观点

问题：图表只是数据截图。

修正：标题改为洞察句；高亮关键点；删除无关系列。

### 反例：模板很花但不服务内容

问题：装饰抢走注意力。

修正：降低装饰层级，回到结构和结论。

## 2. 视频反例

### 反例：PPT 自动播放式视频

问题：没有镜头语言，没有时间轴设计。

修正：按旁白句子拆 scene，补画面 cue 和运动 cue。

### 反例：字幕遮挡主体

问题：关键画面被遮挡。

修正：设置字幕安全区，必要时加半透明底板。

### 反例：BGM 太满

问题：听不清旁白，内容显得廉价。

修正：ducking、EQ 避让、减少编曲层。

## 3. 美术反例

### 反例：所有元素都很突出

问题：没有层级。

修正：只保留一个主焦点，其余降权。

### 反例：颜色无语义

问题：同一颜色一会儿代表风险，一会儿代表增长。

修正：建立色彩角色表。

## 4. 音乐反例

### 反例：情绪过度煽情

问题：财经/治理内容失去专业感。

修正：降低和声戏剧性，改为稳定低密度背景。

### 反例：循环点突兀

问题：视频听起来像拼接。

修正：淡入淡出、延长段落、找自然循环点。
