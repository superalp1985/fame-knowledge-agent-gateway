# 建木知识网层级化重构设计 v0.1（2026-05-20）

## 1. 背景与决策

2026-05-20，经过 Fineval / 上财题验证与公式解析器 Round 2、Round 3a~3g 后，建木知识网达到：

- 34/34 subjects perfect
- 1151/1151 correct
- bad=0
- need_patch 从 312 降至 144

但继续围绕上财题 residual 做题干模板，会越来越接近“题库适配器”路线。老板提出顾虑：用上财题继续训练/补丁，可能违反打榜潜规则；但当前知识网本身非常宝贵。

因此本项目方向切换为：

> 从“题库 residual → 补题干模板”转为“现有知识点 → 学科层级化 → 规律抽象化 → 泛化能力增强”。

本阶段不以继续刷题库 residual 为主，不先改判题主流程，而是先建立学科骨架与知识节点挂载体系。

## 2. 当前判断

现有问题不是知识点不足，而是：

- 当初搭网以知识点优先，不是层级优先；
- 底层事实、公式、法规、定义较丰富；
- 上位概念、模块归属、适用条件、题型规律、例外保护还没有系统化；
- 因此表现为原题/近似题很强，但抽象迁移和自然解释仍需增强。

当前建木更像“强题库脑 / 专家题库脑”，下一阶段目标是升级为“财经学科脑”。

## 3. 目标层级

基础层级采用老板确认的结构：

```text
学科
 └─ 模块
     └─ 上位概念
         └─ 子概念
             └─ 公式 / 法规 / 定义 / 题型
                 └─ 典型题 / 变形题
```

建议增强为：

```text
学科
 └─ 模块
     └─ 上位概念
         └─ 子概念
             ├─ 定义
             ├─ 公式
             ├─ 法规 / 制度口径
             ├─ 适用条件
             ├─ 易混点 / 例外
             ├─ 题型规律
             └─ 典型题 / 变形题
```

原则：典型题/变形题是验证样例，不是规则源头；题库异常进入 exception，不污染通用知识。

## 5. 知识节点卡片格式草案

```yaml
id: finance.investments.asset_pricing.capm
name: 资本资产定价模型
subject: 金融学
module: 投资学
parent: 资产定价
type: formula
definition: 预期收益率由无风险利率、市场风险溢价和 beta 决定
formula: E(R_i)=R_f+β(E(R_m)-R_f)
applies_when:
  - 题干给出无风险利率、市场收益率、beta
  - 问必要收益率、预期收益率或证券市场线
not_applies_when:
  - 题干给出题库特殊口径并与标准公式冲突
pitfalls:
  - 百分数换算
  - alpha 是否单独给出
  - 题干问“不正确的是”时需反向选择
related:
  - beta
  - 证券市场线
  - 风险溢价
question_patterns:
  - 根据CAPM
  - 必要收益率
  - 预期报酬率
examples:
  - 典型 CAPM 数值题
exceptions:
  - source: fineval_val
    note: 标准公式与题库 gold 冲突的题不进入通用公式层
```

## 6. 迁移纪律

1. 不再优先围绕题库 residual 堆题干模板。
2. 先盘点现有知识点分布，再建立层级映射。
3. 公式/法规/定义进入通用层；题库异常进入 exception 层。
4. 标准公式与题库 gold 冲突时，不把冲突题写成通用知识。
5. calc 输出未来应区分“解释文本”和“最终答案锚点”，避免中间数字抢答。
6. 所有改动先做只读文档与结构化映射，不直接改判题主流程。
