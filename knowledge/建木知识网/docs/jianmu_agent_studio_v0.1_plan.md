# 建木 Agent Studio v0.1 方案

> 连续项目：建木知识网的知识资产生产 Agent 工作台

## 1. 目标
把建木知识网接成一个优先调用内部知识、必要时联网补充的单窗口 Agent：
- 备课
- 研究
- 课件生成
- 视频脚本/成片生成
- 课程资产沉淀

## 2. 设计原则
1. **建木优先**：一切内容优先从知识网取证据。
2. **联网补充**：只有在知识网不足时才搜索外网。
3. **成熟即用**：尽量整合现成开源项目，不自研轮子。
4. **单窗口体验**：用户只面对一个 Agent 窗口。
5. **连续项目**：文档、配置、模板、输出都保留在 E 盘建木目录。

## 3. 推荐架构
### 3.1 中控层
- Claw Code 负责任务编排、工具调用、文件管理、结果汇总。

### 3.2 知识层
- 建木知识网：主知识源、主证据源、主资产库。
- Web 搜索：临时补充证据源。

### 3.3 生产层
- 研究简报
- 课程大纲
- 逐页讲稿
- PPT
- 视频脚本
- 字幕
- 配音
- 成片

### 3.4 工具层
优先接入成熟项目：
- 搜索/抽取：SearXNG、Firecrawl、trafilatura、readability
- 课件：Marp、pptxgenjs、python-pptx
- 图表：Mermaid、ECharts、matplotlib
- 音频：edge-tts、ElevenLabs、ffmpeg
- 视频：ffmpeg、MoviePy、Remotion
- 编排：轻量状态机优先，重型 agent 框架后置

## 4. 第一版范围

- 生成研究简报
- 生成课程大纲

### v0.2

### v0.3

## 5. 风险控制
- Web 内容默认不入库
- 政策/财税/制度类内容必须带来源
- 课件内容必须可追溯到建木知识网或明确外部来源
- 任何自动写回知识网的动作先走审核

## 6. 当前计划
1. 调研成熟开源项目，优先选择接入最简单的。
2. 定义 Agent 输入输出协议。
3. 搭建 E 盘工程目录。
4. 跑通“研究简报 → 课程大纲 → PPT 初稿”链路。
5. 再接视频链路。

## 7. 桌面封装：Tauri

老板补充并确认：最终 Agent 窗口建议采用 **Tauri** 封装。

### 选择理由
- Rust 底层 + WebView2 前端，体积极小。
- 内存占用低，适合长期驻留的本地工作台。
- 安全边界清晰，适合本地知识资产、虚拟系统、沙盒工具调用。
- 比 Electron 更轻，避免为了一个 Agent 窗口带一整套 Chromium。

### 定位
- Tauri 作为最终用户界面外壳。
- Claw Code / Python / Node / 开源工具作为后端工具层。
- 前端只负责交互、任务状态、文件预览、成果下载，不承担核心推理。

### 开发顺序
1. v0.1 先跑通 CLI/文件型流水线。
2. v0.2 接 Tauri 单窗口 UI。
3. v0.3 加任务队列、进度条、产物预览、配置面板。

## 8. 环境封装策略
- Agent 不只封装 UI，还要把运行环境一起封进去。
- 目标：安装到任意电脑，都能直接用。
- 中控仍由 Claw Code 负责，后台调度成熟开源工具，最终统一输出。
- 这意味着：配置、依赖、缓存、沙盒策略、工具适配器都要尽量本地化和可移植。

## 9. API 网关：统一入口与集中治理

老板补充：在中控 Agent 前置一个 API 网关，实现“一个入口，集中治理”。

### 定位
- API 网关位于 Tauri UI 与 Claw Code 中控之间。
- 用户和前端只与网关打交道。
- 内部工具、AI 模型、知识网、搜索、PPT/视频生成器都由网关统一封装。

### 价值
- 统一鉴权与权限控制
- 统一任务入口
- 统一日志与审计
- 统一限流与队列
- 统一模型/工具调用协议
- 统一错误处理与重试
- 统一结果输出格式

### 架构位置
```text
Tauri UI
  ↓
API Gateway
  ↓
Claw Code 中控
  ↓
Tools / Models / Jianmu Knowledge / Web / PPT / Video
```

### 第一版实现建议
- v0.1 可先用本地 FastAPI 作为网关原型。
- 对外暴露 `/tasks`, `/runs`, `/artifacts`, `/health`, `/config` 等接口。
- 内部先调用本地脚本和 Claw Code 流水线。
- 后续再扩展权限、审计、插件注册和工具沙盒。

## 10. 重点成熟模块接入
- DocAgent：长文档理解 / 大纲 / 审查。
- DeepPresenter / PPTAgent：幻灯片生成。
- PresentAgent-2：文档到视频全流程。
- Code2Video：动画教学片段增强。
- 这些模块全部作为 Claw Code 的后台工具，不改变主脑结构。
